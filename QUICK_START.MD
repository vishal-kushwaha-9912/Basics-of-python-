# Quick Start 🚀

Get up and running in **5 minutes**!

---

## ⚡ Fast Setup (2 minutes)

### Already Have Python 3.8+?

```bash
# 1. Clone repository
git clone https://github.com/vishal-kushwaha-9912/python-basics.git
cd python-basics

# 2. Create & activate virtual environment
python -m venv venv

# Windows:
venv\Scripts\activate

# macOS/Linux:
source venv/bin/activate

# 3. Done! ✅
```

**No Python?** Install from [python.org](https://www.python.org/downloads/) (5 minutes), then come back.

---

## 💻 Run Your First Program (1 minute)

```bash
# Make sure you're in the repo and venv is activated
python datatypes.py
```

**Should output:** Examples of Python data types (int, float, str, bool)

## 🐛 Common Issues? Quick Fixes

| Problem | Fix |
|---------|-----|
| "python: command not found" | Install Python from [python.org](https://www.python.org/) |
| "venv not activating" | Use full path: `source /full/path/venv/bin/activate` |
| "ModuleNotFoundError: jupyter" | Run: `pip install jupyter` |
| "Can't run .py files" | Make sure you're in the repo folder: `cd python-basics` |
| "Port 8888 already in use" | Use: `jupyter notebook --port 8889` |

**Still stuck?** See [SETUP.md](SETUP.md) for detailed help.

## 📖 Learning Tips

1. **Code Every Day** — Even 30 minutes helps
2. **Type Code Yourself** — Don't just copy-paste
3. **Modify Examples** — Change values and see what happens
4. **Read Errors** — They're helpful, not scary
5. **Use Comments** — Write `# like this` to explain your code
